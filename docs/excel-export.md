# 项目任务 Excel 导出

入口为项目页面右上角「导出 Excel」，设置 → 项目 → 常规 → 任务中也保留同一入口。弹窗默认导出全部任务，也可按创建时间（默认）、更新时间、开始时间或截止时间选择日期范围。范围包含开始日与结束日全天，按浏览器时区计算；未填写所选日期的任务不进入日期范围。文件项目配置中注明筛选条件；无匹配任务时仍生成表头与配置。原 JSON 导出及导入格式保持兼容。

文件使用真正的 `.xlsx` 格式，包含任务清单与项目配置。不限定日期时范围为该项目全部任务，包括计划、归档任务，不依赖看板当前筛选或分页。任务清单包含编号、标题、完整说明、状态显示名、优先级、负责人、标签、日期和全部自定义字段；数字字段保存为数值，未填字段保持空白，不用默认值替代空值。日期按导出浏览器的时区展示，并在项目配置中注明时区。

长文本超过 Excel 单元格限制时按顺序分段保存到额外的长文本工作表，主表提示查看该表。用户输入始终按文字写入，不作为公式执行。

后端以只读一致性快照提供数据，重新检查项目所属工作空间，校验项目及任务读取权限，字段值两端均限制在项目内。文件在浏览器生成，不上传第三方服务。ExcelJS 按需加载，不增加 API 运行时依赖。

验收：空项目有表头，超过 100 条任务不截断，小数/零/空白正确区分，公式样式文本按文字导出，超长说明可以完整拼回，未授权或跨项目访问被拒绝，导出不改变任务及配置。
